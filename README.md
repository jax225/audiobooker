# 🎧 AudioBook Maker

Простое Windows-приложение для быстрого создания аудиокниг из текстовых файлов.

**AudioBook Maker** выполняет два шага:

*Файл с текстом должен быть обязательно в формате `.txt` c кодировкой `UTF-8`.*

1. Разбивает текст из `.txt` на абзацы по 700+ символов до знака [.][!][?] и сохраняет в `.html` (с тегами `<p>`).
2. Озвучивает получившийся HTML с помощью нейросетевых голосов Microsoft Edge (бесплатно) и сохраняет каждый абзац в отдельный MP3-файл.

Приложение собрано в один исполняемый файл — не требует установки Python или дополнительных библиотек.

## 🚀 Как использовать

1. **Скачайте** `AudioBookMaker.exe` и запустите его.
2. **Шаг 1: TXT → HTML**
   - Нажмите **«Обзор»**, выберите ваш `.txt` файл.
   - Нажмите **«Создать HTML»**.
   - HTML-файл появится **в той же папке, где находится EXE**.
3. **Шаг 2: HTML → MP3**
   - Нажмите **«Обзор»** (рядом с полем «HTML файл») и выберите созданный `.html`.
   - Нажмите **«Обзор»** (рядом с полем «Папка для MP3») и укажите, куда сохранять аудио.
   - При необходимости измените голос, скорость речи и номер абзаца для продолжения.
   - Нажмите **«Запустить озвучку»**.
4. В нижней части окна отображается лог процесса и прогресс-бар. Вы можете остановить генерацию в любой момент кнопкой **«Остановить»**.

## 📖 Автоматическое определение глав

Во время озвучки программа автоматически ищет в тексте конструкции вида:

`Глава [номер главы цифрой]. [Предложение до 7 слов]`

Например:

`Глава 1. Начало сентября`

Если такая конструкция найдена, программа добавляет название главы в имя MP3-файла.  
Пробелы в названии заменяются на подчёркивания.

Пример имени файла:

`000001_Глава_1_Начало_сентября.mp3`

Если конструкция не найдена, файл сохраняется, как обычно:

`000002.mp3`

## ✅ Проверка полноты озвучки

После завершения озвучки рекомендуется убедиться, что все абзацы были успешно преобразованы в MP3.

1. Откройте папку с MP3-файлами.
2. Нажмите `Ctrl+A`, чтобы выделить все файлы.
3. Кликните правой кнопкой мыши по любому выделенному файлу — в открывшемся меню или в свойствах будет показано **количество элементов**.
4. Сравните это количество с номером последнего файла (например, если последний файл начинается с `001864`, то всего должно быть 1864 файла).
5. Если количество не совпадает, запустите озвучку заново, указав в поле **«Начать с номера»** значение `1`.  
   **Ничего не удаляйте и не ищите вручную** — программа автоматически пропустит уже существующие файлы и создаст только недостающие.

## ⚙️ Особенности

- **Устойчивость к сетевым сбоям** – встроены повторные попытки при разрыве соединения.
- **Продолжение с места остановки** – можно указать номер абзаца (например, `728`), чтобы докачать недостающие файлы.
- **Автоматическое создание папки** для MP3, если она не существует.
- **Интуитивный интерфейс** – всего два шага, не нужно запоминать ключи командной строки.
